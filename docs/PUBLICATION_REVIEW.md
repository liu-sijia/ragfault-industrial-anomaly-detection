## 发布前必须确认

1. 项目所有者是否有权公开全部源码和知识文本。
2. 选择合适的软件许可证；当前未附加许可证。
3. 是否希望公开 HAI 扩展中的既有攻击区间与字段配置。
4. 首次 Git 提交前再次运行敏感信息和大文件检查，并检查 `git diff --cached`。
