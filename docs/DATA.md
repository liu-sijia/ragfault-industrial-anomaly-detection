# 数据准备与隐私说明

## 仓库不包含数据集

为避免重新分发真实数据、第三方数据或可能含敏感信息的样本，本公开候选副本不包含原始 CSV、处理后 CSV、ZIP 数据包或上传样例。请从数据集官方来源获取，并遵守其许可条款。

## 默认流程

将有权使用的数据放在被 `.gitignore` 排除的 `data/` 下，或通过 Web 页面上传。默认配置期望以下特征：

- `Accelerometer1RMS`
- `Accelerometer2RMS`
- `Temperature`
- `Volume Flow RateRMS`

代码还需要可识别的时间列与异常标签列。具体兼容名称以 `src/data_processor.py` 的字段识别逻辑为准。不同数据源的采样频率、单位、基线区间和标签语义必须人工核对，不能只改列名。

## HAI 扩展

复制配置样例到 `.gitignore` 已排除的本地文件，或直接通过 `--config` 指定另一份本地配置，然后设置 `raw_gzip` 与 `processed_csv` 路径。样例中的特征和区间来自原项目既有实验配置，但仓库不附带数据；若数据版本不同，应重新校验行号、攻击区间、字段和基线长度。

## 上传前检查

- 只使用你有权处理的数据。
- 移除人员、工厂、资产编号、网络地址、地理位置等标识。
- 不上传密钥、账号、生产配置、日志中的凭据或专有工艺参数。
- 检查 CSV 单元格和 ZIP 内部文件名，因为它们也可能包含敏感信息。
