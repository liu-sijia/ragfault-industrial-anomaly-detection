# 演示说明

## 建议演示路径

1. 展示首页的流程说明和知识库选择。
2. 上传已脱敏且字段兼容的小型 CSV/ZIP。
3. 展示窗口数量、异常比例、混淆矩阵和主要指标。
4. 打开单个窗口，说明统计特征、模型理由与检索证据的关系。
5. 使用不含敏感信息的工程说明与字段表构建新场景知识库，再展示场景切换。

## 演示时应明确

- 这是研究原型，模型判断不能替代安全系统或人工复核。
- 页面指标根据本次上传数据的标签与模型输出即时计算。
- 不同模型版本、硬件、数据版本和随机性会影响复现结果。
- 首次构建索引或加载嵌入模型可能较慢。

## 无数据情况下

可以只展示代码架构、默认知识文本和 Web 界面。不要为了演示方便把真实数据提交到仓库。
